How it runs
  1. Define the reference once — naming, lifecycle, routing, required fields.
  2. Diff each client account against it on the monthly run.
  3. Give every consultant the same target instead of their own taste.
  4. Watch all accounts in one view: which are drifting, which need you this week.
What it is worth

The difference between a team of five consultants and five people who each do it their own way.

Watch out for

A reference nobody agrees with becomes a report everyone ignores. Build it with the team, not for them, or it will not stick.
