How it runs
  1. Generate the description — already done by the audit.
  2. Dry run: show exactly what will be written, to what, before anything moves.
  3. Write, recording the previous value for every field touched.
  4. Keep the log. Revert is one command, not an archaeology project.
What it is worth

Watch out for

This writes to a live client account. It needs consent in writing, a dry run every time, and a revert path you have actually tested — not one you assume works.
