Before you start

Four ways this goes wrong

Alert fatigue
Kills phase 1

A drift report that fires on every change becomes a folder rule within two months, and the retainer loses the artefact justifying it. The graph already knows what has a footprint — report only changes that reach something, and let the rest go unmentioned.

Production writes
Kills phases 2 and 4

One bad write to a client's live account costs more than every phase here earns. Dry run by default, log every previous value, test the revert path on a sandbox before it ever runs on a customer — and hold the tool to the same blast-radius standard it holds them to.

Consent, after the fact
Kills the benchmark

Aggregated benchmarks need permission written into the agreement before collection starts. Asking twenty existing clients for retrospective consent is a worse conversation than adding one clause today.

Building ahead of demand
Kills the roadmap

Phase 1 is a week and pays immediately. Phases 3 and 4 are a month each and pay only once several clients are on the cycle. Run phase 1 with two real clients for a quarter before committing to anything below it — if the monthly note does not change renewal conversations, the rest of this plan is wrong.
